# Portfolio - Amina Nauman

This folder contains a small portfolio website for the Web Engineering lab. It includes:

- `home.html`, `hobbies.html`, `skills.html`, `gallery.html`, `contact.html`
- `style.css` — external styles used by all pages
- image assets used in the gallery

How to preview locally

1. Open the folder in VS Code or any file manager.
2. Double-click `home.html` to open in your browser, or use the Live Server extension.

Push this folder to GitHub

Run these commands from inside the `files` folder (replace `YOUR_REPO_URL`):

```bash
git init
git add .
git commit -m "Add portfolio for Web Engineering lab"
git branch -M main
git remote add origin YOUR_REPO_URL
git push -u origin main
```
